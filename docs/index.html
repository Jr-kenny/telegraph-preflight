A preflight check for token listings. Real checks, real receipts, proven on-chain.

Testnet — Sepolia

Try it live

Runs paid Telegraph checks, a honeypot sell simulation, and a DexScreener cross-check, then anchors the execution record on Sepolia and runs the verifier.

Live checks typically take 30 to 60 seconds because each check waits for real Telegraph receipts and a Sepolia anchor confirmation.
